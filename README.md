Entry for the [make.fun "One-Line Office Jokes" bounty](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc): a program that writes one single-line joke about office life to `/output/entry.txt`.

The line:

> My manager said my out-of-office reply was unprofessional, so I changed it to 'I'm in a meeting' — permanently.

## Run

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` by default). Standard library only, no network, deterministic — every run writes the same bytes.
